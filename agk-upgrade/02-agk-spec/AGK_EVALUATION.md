# AGK Evaluation

## Definition

An Eval is a versioned measurement of a declared subject against a method and dataset. Audit investigates systematically. Verification decides acceptance. A Gauntlet orchestrates several gates.

## Targets

Evals can target Model, Prompt, Skill, Agent, OS, Flow, Workforce, Artifact, retrieval strategy, memory strategy or routing policy.

## Contract

An Eval records subject and version, dataset and version, evaluator or judge, metrics, baseline, environment, Runtime, Budget, result, uncertainty, evidence and provenance.

## Hermes mapping

Hermes includes eval directories, goal judging, verification commands, trajectories and batch execution. Reuse these as evaluator mechanisms. AGK adds first-class Eval identity, cross-object targets, dataset governance, baselines, calibration and promotion decisions.

## Independence

Critical producer-side testing is not independent Verification. A model judge may gate only after calibration for the relevant task class. Dissent and unresolved cases remain visible.

## Regression

Published Definitions link to regression Evals. Package and upstream upgrades run applicable baselines before deployment.
