## Hard gates

1. Executable Hermes adapter implementation depends on canonical execution state, sandbox, signed bundle, supervisor, brokers, Context adapter and event journal.
2. Oracle depends on Project and OS Installation state.
3. Workforce depends on Team, Agent, Oracle and package contracts.
4. Canvas structural editing depends on semantic commands and optimistic concurrency.
5. Architect depends on all target schemas, diff and validation.
6. Learn, Deals and Self bridges depend on cross-surface permission policy.
7. Marketplace depends on package snapshots, grants, provenance, evals and trust tiers.
8. Labs promotion depends on immutable versions, evals and independent approval.

## Parallel lanes after the control-plane spine

- Artifact and Knowledge stores
- signed Package and Runtime bundle work
- canonical AGK Web and Tauri shell contracts
- Hermes UI behavior extraction spike

No executable Agent adapter lane starts in parallel with the domain and security prerequisites it consumes.
