# Refined Vision Diff

## What changed

1. The canonical AGK Web shell and its Tauri desktop wrapper expose a top bar that switches complete contextual layouts for Collective, Learn, Build, Deals and Evolve.
2. Build is organized as Operate, Build and Inspect experiences rather than chat alone.
3. The Organization Canvas becomes recursive across Project, Workforce, Team and OS Installation.
4. OS execution composition is made explicit: Agents, Skills, Tools, MCP, scripts, Flows, Loop definitions, Automations, Knowledge, Memory, evals and Runtime requirements.
5. Human collaboration, Learn, Deals and Self are described as bounded product domains over one shared graph.
6. Cross-surface privacy and permission decisions become explicit architecture requirements.
7. Packaging, provenance, trust tiers and future marketplace paths are expanded.

## What stayed identical

- project-first and outcome-first thesis
- Organization as tenancy and Project as operational organization
- Hermes as bounded execution foundation
- Agent as worker and Oracle as owner
- OS as reusable domain intelligence, not prompt
- Team versus Workforce distinction
- one canonical object graph
- Memory, Knowledge, Context and Artifact separation
- model and provider agnosticism
- upstream compatibility and reuse-first doctrine
- self-improvement may propose and may never ratify

## What was misunderstood in the prompt

- OS autonomy does not make the reusable Definition own live state. Installation and Oracle preserve that boundary.
- Graph is a projection and engine structure, not a top-level AGK object.
- Hermes Project is not AGK Project.
- Hermes Goals, Loops and kanban rows are implementation mechanisms, not canonical AGK domain objects.
- Retired surface names cannot enter canonical contracts through UI copy.

## Existing Stepper work that remains valid

The pinned Stepper still provides 6,441 Feature mappings, 1,197 planned Steps, a cycle-free graph, 29 contracts, 50 named user journeys, security threat models and a technically passing Pre-Build audit. Source authority, object invariants, Runtime protocol, permissions, events and F22 bounded Hermes integration remain valid.
