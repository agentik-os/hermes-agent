# Ontology Corrections

## Preserved canonical ontology

- Organization is tenancy.
- Project is outcome-oriented operational organization.
- Agent performs work.
- Oracle owns a persistent domain.
- OS Definition packages reusable domain intelligence.
- OS Installation binds the Definition to real Project operation.
- Team is a bounded group.
- Workforce is a deployed organizational system.
- Flow is an authored process.
- Loop is a bounded iterative controller.
- Harness is logical execution configuration.
- Runtime is physical execution environment.
- Memory retains experience.
- Knowledge retains reusable truth.
- Artifact retains managed work.

## Reconciled refined OS statement

The sentence "OS is persistent, composable domain intelligence and execution system" is implemented through three layers:

```text
OS Definition       persistent reusable operational intelligence
OS Installation     scoped configuration and executable bindings
Oracle               persistent responsibility and live domain ownership
```

This preserves the operator's autonomous multi-Agent system while preventing Definition state leakage.

## Surface vocabulary

Canonical universe ids and labels are Collective, Learn, Build, Deals and Evolve under AD-314. Self remains the private internal domain beneath Evolve. Build contains Operate, Design, Code and Inspect modes.

## Graph and Flow

Use Flow for the authored process type. Graph remains an engine structure or projection. The Canvas edits objects and typed relationships.
