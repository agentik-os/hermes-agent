# Self Alignment

## Role

Self is the private personal intelligence surface for goals, decisions, Journal, routines, health, relationships, learning, money and personal strategy.

## Shared intelligence

A Personal OS uses the same OS Definition and Installation model as Build. It can bind Agents, Skills, Tools, Knowledge, Memory, scripts, Flows, Automations and evals. It does not create a second PersonalOS architecture.

## Privacy

Self data defaults to user scope, private zone and no cross-surface access. Build Organizations, Deals matching, Learn recommendations and Community cannot read it without an explicit field-level grant, purpose and expiry.

## Personal Oracle

A Self Oracle is architecturally possible but remains a proposed product choice. It earns existence only if it owns long-term personal alignment state, cross-OS coordination, decisions and escalation beyond what one OS Installation provides.

## Hermes reuse

Hermes personal memory, scheduler, Skills, Tools and agent execution are useful foundations. They must run through the Self-private Context Firewall and cannot write shared Organization Memory by default.

## Priority

P2 bounded foundation after identity, permissions, Memory, Knowledge, OS and cross-surface grants. Advanced pattern engines and recommendation loops are later.
