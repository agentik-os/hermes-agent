## New implementation task families

The 36 planning tasks in `../06-implementation/tasks.json` express the delta. They do not replace the 1,197 Stepper Steps. A future Stepper patch should map these task families to existing ids, preserving ids where semantics remain and inserting new ids with source references where genuinely new.

## Validation preservation

The previous validation remains evidence for the pinned snapshot. It is not silently transferred to a modified Step graph. A future patch must regenerate the Stepper and rerun the independent audit. Presence coverage is not semantic validation.

## Gate consequence

Recommended action remains `KEEP_CLOSED` for implementation. Architecture work can continue. Builder execution requires a new exact-snapshot audit and affirmative operator decision.
